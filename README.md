# 🍽️ Zomato Dine Insight 360: Restaurant Analytics Dashboard

An interactive Power BI dashboard analyzing 9,551 restaurants across 15 countries and 141 cities.



## 📌 Objective
Understand restaurant distribution, ratings, pricing, table booking and online delivery trends.

## 🔍 Key Insights
- India accounts for 8,652 restaurants; New Delhi leads cities with 5,473
- Average rating is 2.91; most restaurants are rated 3 or 4
- Only 12.12% offer table booking and 25.7% offer online delivery
- Most restaurants fall in the $0-10 price range for two

## 🛠️ Tools & Techniques
- Power BI Desktop, Power Query, DAX
- Data modeling (see `docs/data_model.png`)
- Custom columns: rating groups, price buckets
- Slicers: Year, Quarter, Country
- Pages: HOME, MAP
